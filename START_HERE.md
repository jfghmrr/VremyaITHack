# Первый запуск Перепева

Для локального сайта нужны запущенный Docker Desktop либо Docker Engine с Compose 2.24.4 или новее. На Windows используется режим Linux-контейнеров. При первой сборке нужен интернет; Node, Rust и базы отдельно устанавливать не надо.

## Установка

Склонируй репозиторий или распакуй его архив. Открой терминал в папке с `compose.yaml` и `Dockerfile`:

```sh
git clone https://github.com/jfghmrr/VremyaITHack.git
cd VremyaITHack
docker compose up --build -d --wait --wait-timeout 180
```

Дождись завершения сборки и открой **http://localhost:8080**. Разреши микрофон и используй наушники. Новая установка создаёт пустую базу и сама применяет миграции. Файл `.env` для обычного запуска не нужен.

Проверка: **http://localhost:8080/api/health** должен возвращать `ok`, `db` и `valkey` со значением `true`. Поле `worker: false` допустимо, если GPU-обработчик не подключён: в этом случае работает браузерная оценка.

## Дополнительные возможности

Точная оценка голоса и подготовка своих треков требуют отдельного обработчика. Его установка описана в [deploy/gpu-worker/README.md](deploy/gpu-worker/README.md). Секрет обработчика хранится на его компьютере, в настройках API нужен только SHA-256 секрета.

Кнопки Яндекс ID и VK ID появятся после настройки приложений по [docs/oauth-setup.md](docs/oauth-setup.md). До этого можно создать кабинет по почте и паролю.

## Остановка

```sh
docker compose down
docker compose up -d --wait --wait-timeout 180
```

Данные остаются в томах Docker. Не добавляй `-v` к обычной остановке: этот флаг удаляет тома.

## Если запуск не удался

```sh
docker compose ps -a
docker compose logs --tail=100
```

При ошибке подключения проверь, что Docker запущен. При ошибке скачивания проверь доступ к реестрам образов, Cargo и npm. Если сборка завершается сообщением `killed`, проверь свободную память и диск; для первой сборки стоит выделить Docker около 8 ГБ памяти и иметь 15 ГБ свободного места.

Если порт 8080 занят, создай `.env` рядом с Compose-файлом:

```dotenv
PEREPEV_PORT=8081
APP_ORIGINS=http://localhost:8081,http://127.0.0.1:8081
```

Повтори запуск и открой **http://localhost:8081**. Порт и разрешённые адреса меняются вместе. Все примеры настроек собраны в [.env.example](.env.example).

Две отдельные установки не соединяются автоматически. Для живой дуэли и режима «Вместе» оба игрока открывают один сервер. Доступ с другого устройства требует HTTPS; варианты размещения описаны в [OPERATIONS.md](OPERATIONS.md).

Исходники, песни, шрифты и графика входят в репозиторий. Личные аккаунты, локальные базы и кеши моделей не входят. `fixtures/legacy/perepev.sqlite` содержит вымышленные тестовые данные и при обычном запуске не импортируется.
