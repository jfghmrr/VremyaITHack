# Проделанная работа

Обновление репозитория — 20 октября 2026 года, версия из папки `Perepev 3`. Проект команды MugSize для хакатона «Время IT» от ГУАП.

## Что появилось в новой версии

**Совместное пение.** В комнате можно выбрать режим «Вместе»: сервер распределяет строки между двумя игроками, считает их партии и общий результат. После песни доступно прослушивание двух настоящих голосов с минусом. Для этого нужны отдельные согласия обоих участников; без них звучит синтезированная мелодия. Добавлены повторное исполнение, восстановление результата и обработка задержек загрузки записей.

**Работа с голосом.** Доработаны определение высоты в браузере, отсечение шума и отображение линии. На проверке микрофона учитывается тихий голос, а визуальная тональность сцены меняется плавнее. Это не заменяет проверку точности на записях живых певцов.

**Свои песни.** После нейросетевой подготовки пользователь может исправить текст и время слов. Обработчик уточняет границы слов по активности вокала и отбрасывает часть ошибочных вставок распознавания.

**Телефон.** Добавлены нижнее меню, компактная главная и проверка микрофона. Во время пения меню скрывается. Уменьшен размер декоративных изображений и шрифтов, часть оформления загружается по мере необходимости.

**Матчи и кабинет.** Доработаны рейтинговая очередь, переподключение и реванш. API, схемы сообщений и клиент обновлены вместе. Миграция `0007_match_mode.sql` добавляет режим матча и согласие на передачу голоса партнёру.

## Что уже было реализовано

Клиент работает на SvelteKit, API — на Rust. Общее ядро `scoring-core` собирается для сервера и браузера через WebAssembly. В игре есть одиночное пение, тренировка трудных мест, живые дуэли, рейтинговый подбор, вызов-призрак, кабинет, история, друзья и достижения.

Каталог содержит 32 фрагмента: 14 русских и 18 английских. Для записей сохранены источники, лицензии, эталоны мелодии, слова, минусы и вокальные подсказки.

Отдельный Python-обработчик запускает Demucs, torchcrepe и Whisper на собственном компьютере команды. Он готовит свои треки и проверяет одиночные попытки. Браузерная оценка доступна и без него. Свою модель команда не обучала.

Для размещения подготовлены Docker, конфигурации прокси, резервное копирование и установщик GPU-обработчика на Windows. Есть вход по почте, интеграции Яндекс ID и VK ID, согласия, обращение владельцу, выгрузка и удаление данных.

## Материалы проекта

Обновлены описание, архитектура, протокол и инструкция по обслуживанию. Добавлена [презентация для защиты](presentation/Презентация_Mugsize.pptx). Причины выбора стека собраны в [технических решениях](docs/technology-decisions.md).

Результаты проверки этой версии — в [отчёте перед публикацией](docs/release-check.md). Старые отчёты и GPU-бенчмарк сохранены с датами: их результаты не относятся автоматически к новой версии.

## Что предстоит

Нужны испытания на живых певцах и реальных телефонах, настройка порогов по экспертным оценкам и проверка нагрузки на очередь GPU. Приглашения из списка друзей и синхронизация локальных достижений между устройствами пока не реализованы. Вызов по ссылке на свой приватный трек не предоставляет доступ другому пользователю.
