# GPU-воркер Перепева на Windows

Воркер — программа на ПК команды с видеокартой NVIDIA (RTX 3070 Ti). Он сам забирает у сервера задания:

- **оценка исполнения**: мелодия, спетые слова и проверка, не звучала ли песня из динамика;
- **свой трек пользователя**: разделение на минус и голос, мелодия, распознанные слова.

Воркер только обращается к серверу по HTTPS. Входящие порты на ПК не открываются, роутер настраивать не нужно.

## Что нужно

- Windows 10 или 11, 64 бит, учётная запись администратора.
- Видеокарта NVIDIA с актуальным драйвером (для CUDA 12.8 — версии 570 или новее). Без видеокарты воркер работает на процессоре, но оценка не уложится в 20 секунд.
- `winget` (приложение «Установщик приложений» из Microsoft Store; в Windows 11 уже есть).
- Около 15 ГБ на диске C: и интернет во время установки: PyTorch с CUDA занимает около 3 ГБ, модели — около 2 ГБ.
- Полная копия репозитория: `setup.ps1` берёт код из папки `gpu-worker` в корне.
- Адрес сервера и токен воркера (см. ниже).

## Токен воркера

Токен знает только воркер. Сервер хранит его SHA-256 в переменной `WORKER_TOKEN_SHA256`. Создать пару можно на Mac или Linux:

```sh
TOKEN=$(openssl rand -hex 32)
echo "$TOKEN"                                        # ввести в setup.ps1
printf %s "$TOKEN" | shasum -a 256 | cut -d' ' -f1   # записать в WORKER_TOKEN_SHA256 в .env сервера
```

Токен не публикуйте, не пересылайте в общие чаты и не добавляйте в репозиторий.

## Установка

1. Откройте PowerShell от имени администратора: правый клик по «Пуск» → «Терминал (администратор)».
2. Перейдите в папку скрипта:

   ```powershell
   cd C:\путь\к\Perepev\deploy\gpu-worker
   ```

3. Посмотрите план без изменений:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1 -DryRun
   ```

4. Установите:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1 -ServerUrl https://perepev.lumnex.ru
   ```

   Токен скрипт спросит со скрытым вводом. Параметр `-Token` тоже работает, но тогда токен останется в истории PowerShell.

Скрипт выполняет 10 шагов:

1. Проверяет версию Windows (10 или 11, 64 бит, сборка 17763 или новее) и права администратора.
2. Ищет видеокарту через `nvidia-smi`; если её нет, предупреждает и продолжает на процессоре. Предупреждает, если драйвер старше 570.
3. Ставит `uv` через `winget install astral-sh.uv`, если его ещё нет.
4. Останавливает прежний воркер, закрывает доступ к `C:\Perepev` (только SYSTEM и администраторы) и копирует `gpu-worker` в `C:\Perepev\gpu-worker`.
5. Выполняет `uv sync --extra cuda`: Python 3.12 и PyTorch CUDA 12.8 из индекса, закреплённого в `pyproject.toml` и `uv.lock`.
6. Скачивает модели (`uv run python -m perepev_worker.main --warmup`) и проверяет, что PyTorch видит видеокарту.
7. Шифрует токен через DPAPI в `C:\Perepev\token.dat`.
8. Запускает самопроверку `--selftest`: все модели на синтетическом отрывке и связь с сервером.
9. Регистрирует задачу планировщика `PerepevWorker`: запуск при старте Windows от имени SYSTEM, перезапуск каждую минуту, до 999 раз.
10. Показывает состояние задачи и путь к журналу.

Повторный запуск безопасен: прежний воркер останавливается, код и зависимости обновляются. Так же обновляйте воркер после `git pull`.

## Где что лежит

| Путь | Содержимое |
| --- | --- |
| `C:\Perepev\gpu-worker` | Код воркера и его окружение `.venv`. |
| `C:\Perepev\python`, `C:\Perepev\uv-cache` | Python 3.12 и кеш пакетов uv. |
| `C:\Perepev\models` | Модели Demucs, torchcrepe и Whisper. |
| `C:\Perepev\token.dat` | Токен, зашифрованный DPAPI. Читать файл могут только SYSTEM и администраторы. |
| `C:\Perepev\worker.json` | Адрес сервера и имя воркера (имя компьютера). |
| `C:\Perepev\run-worker.ps1` | Запускает воркер и перезапускает его после сбоя. |
| `C:\Perepev\worker.log` | Журнал. После 10 МБ он переносится в `worker.log.1`. |
| `C:\Perepev\work` | Временные файлы задания. Запись голоса удаляется сразу после каждого задания. |

Менять что-либо в `C:\Perepev` могут только SYSTEM и администраторы: оттуда SYSTEM запускает код и берёт адрес сервера при каждой загрузке Windows. Поэтому установщик в шаге 4 делает владельцем папки группу администраторов и отключает наследование прав от `C:\`, ещё до копирования кода и записи токена.

Почему токен зашифрован ключом компьютера, а не через `ConvertFrom-SecureString`: задача работает от имени SYSTEM. SYSTEM не может расшифровать данные, зашифрованные под учётной записью пользователя. Поэтому используется DPAPI с ключом этого компьютера, а доступ к файлу ограничен правами.

## Проверка работы

```powershell
Get-ScheduledTask PerepevWorker | Get-ScheduledTaskInfo   # LastTaskResult 267009 — задача работает
Get-Content C:\Perepev\worker.log -Tail 30 -Wait          # журнал воркера
Stop-ScheduledTask PerepevWorker                          # остановить
Start-ScheduledTask PerepevWorker                         # запустить
```

На сервере `GET /api/health` возвращает `"worker": true`, если пульс воркера приходил в последние 30 секунд.

## Удаление

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1 -Uninstall
```

Удаляются задача `PerepevWorker` и вся папка `C:\Perepev`: код, Python, модели, токен и журнал. Сам `uv` остаётся; удалить его можно командой `winget uninstall astral-sh.uv`.

## Если что-то не так

| Признак | Что делать |
| --- | --- |
| «Запустите PowerShell от имени администратора» | Откройте терминал администратора и повторите. |
| «nvidia-smi не найден» | Установите или обновите драйвер NVIDIA, перезагрузите ПК, повторите установку. |
| «драйвер NVIDIA … старше 570» или «!!! Видеокарта NVIDIA найдена, но PyTorch её не видит» | Обновите драйвер NVIDIA до 570 или новее, перезагрузите ПК и повторите `setup.ps1`. Иначе воркер считает на процессоре и оценка не укладывается в 20 секунд. |
| «нужны Windows 10 или 11, 64 бит…» | Воркер поддерживает только 64-битные Windows 10 (1809 и новее) и 11. |
| Ошибка `uv sync` или загрузки моделей | Проверьте интернет и свободное место, повторите `setup.ps1`. |
| В самопроверке `server … FAIL` с HTTP 401 | Токен не совпадает с `WORKER_TOKEN_SHA256` на сервере. |
| В журнале `worker exited with code 2` | Сервер отклонил токен; воркер повторяет попытку раз в 5 минут. |
| `/api/health` показывает `"worker": false` | Проверьте журнал, адрес в `worker.json` и доступ ПК к серверу. |

Запасной вариант на время защиты — Mac как воркер на процессоре. Команды описаны в разделе «GPU-воркер» файла `OPERATIONS.md` в корне репозитория.

## Проверка скрипта без Windows

```sh
pwsh deploy/gpu-worker/setup.Tests.ps1
```

Тест запускает только `-DryRun`: в пустой временной папке, с поддельными `winget`, `uv` и `nvidia-smi`. Он проверяет, что план содержит все шаги, на диске ничего не создаётся и токен не выводится.
