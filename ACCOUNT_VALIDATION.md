# Проверка кабинета и новой навигации

13 октября 2026. Docker Compose, Node 22 / Linux ARM64, Nginx и Fastify. Браузер — отдельный Google Chrome с синтетическим микрофоном.

## Что прошло

- Исходные 22 теста Vitest — без изменения DSP, скоринга, эталонов и вызовов.
- Три серверных интеграционных сценария: регистрация/вход/выход, приватная история и идемпотентность сохранения; CSRF/валидация/лимит запросов; смена пароля/отзыв сеансов/перезапуск SQLite. Проверено отклонение попытки с чужим owner.
- TypeScript strict, production-сборка и форматирование.
- Docker собирается и оба контейнера запускаются; база находится в постоянном томе.
- Браузерный сценарий — 31 состояние при 1366×768, 1920×1080, 800 px, плюс регистрация на 390 px. На проверенных настольных состояниях нет вертикального переполнения страницы; на узких нет горизонтального.
- Регистрация с подтверждением пароля, повторный вход после перезагрузки, вход в отдельном браузерном контексте, изменение имени и пароля.
- История первого пользователя не видна второму. Выход убирает текущую запись и ссылку возврата к её разбору.
- Выбор песни сразу открывает микрофон; весь путь через запись, результат, возврат к последнему разбору, копирование вызова и дуэль работает.
- Искусственный HTTP 503 при сохранении: появляется повторная отправка, после неё результат сохраняется, в истории одна попытка.
- Входящий hash-вызов открывается даже из кабинета в уже открытой вкладке.
- JavaScript pageerror в прогоне — 0.

Протокол и воспроизводимый сценарий — `docs/qa/account/checks.json`, `docs/qa/account/check.mjs`. Тест создаёт отдельные аккаунты с адресами в зарезервированном домене example.test, реальная почта не используется.

## Что не проверено и не добавлено

Живые голоса, физические микрофоны, другие браузеры и публичный HTTPS-деплой не проверялись в этой итерации. Email не подтверждается, восстановление забытого пароля не реализовано. Независимый аудит безопасности не проводился. ML пока только в плане эксперимента. Старые отчёты `DOCKER_VALIDATION.md`, `PEREPEV_VALIDATION.md` описывают предыдущую версию без серверного кабинета.
