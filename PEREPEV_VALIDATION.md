# Проверка дизайна «Перепев»

13 октября 2026. Локальный Google Chrome 155.0.8059.40, отдельный временный профиль Playwright.

## Результаты

- `npm test`: 22/22, исходные тесты не изменены.
- `npm run build`: успешно, TypeScript strict и Vite.
- `npm run format:check`: успешно.
- `npm run score:demo`: идеально, +5, −7, задержка 200 мс и вибрато — 100; шум — 23.9; тишина — 0; смена тональности — 87.3 с потерей стабильности.
- `node docs/qa/perepev/check.mjs`: 66 состояний. На проверенных экранах 1366×768 и 1920×1080 нет вертикальной прокрутки страницы; на 800 px нет горизонтального переполнения. Каталог и регистрация также проверены при 390 px.
- Дополнительно проверяется, что блок дуэли не пересекает панель A/B; карточки песен имеют одинаковую высоту, ширину и верхнюю координату.
- Полный путь: каталог → карточка → выбор микрофона → пение → результат → A/B в обоих режимах → переслушивание → репетиция → clipboard → вторая вкладка → призрак → победитель. Проверены пауза, Esc/диалог и повтор R.
- Регистрация: согласие, сохранение после перезагрузки, выход, история и локальный рейтинг.
- Ошибки: запрет доступа, отсутствующий/занятый микрофон, тишина, недоступное хранилище. Проверены фокус, reduced-motion и DPR 2 для каталога и регистрации.
- Ошибок JavaScript и console.error в основном прогоне нет. Протоколы: `docs/qa/perepev/checks.json`, `edges.json`.

## Пределы проверки

Синтетический MediaStream проходит настоящий AudioWorklet/pitchy. Это не прослушивание человеком и не испытание физического микрофона. Edge, Firefox, Safari, Bluetooth и реальный проектор в этом прогоне не проверялись. Коррекция собственного тембра остаётся экспериментальной; надёжный вариант демо — синтезированный ориентир, явно обозначенный в интерфейсе. Регистрация локальная, без серверного аккаунта.

Музыка, эталоны, `src/audio`, `src/scoring`, `src/challenge` и исходные тесты не изменены в этой переработке.
