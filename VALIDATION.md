# Проверки исходного MVP

Этот отчёт описывает предыдущую версию. Актуальный desktop-first прогон и скриншоты: [DESKTOP_VALIDATION.md](DESKTOP_VALIDATION.md).

Проверено 12 октября 2026 года. Это локальный прототип, без публикации.

## Автоматические проверки

- `npm test`: **22 теста, 4 файла, все прошли**.
- `npm run build`: строгая проверка TypeScript и production-сборка Vite прошли. AudioWorklet поставляется отдельным JS-файлом; Tone.js загружается отдельным чанком при выборе коррекции собственного голоса.
- `npm run format:check`: форматирование прошло.
- `npm audit`: известных уязвимостей в установленном lockfile не обнаружено на момент запуска команды.
- `git diff --check`: ошибок пробелов нет.

## Браузер

Изолированный Playwright Chromium, отдельно на dev-сервере и **на production-сборке** через Vite preview:

- Главная, 1440 × 1000 и 390 × 844; дополнительная проверка на ширине 320 px. Горизонтального переполнения нет.
- Виртуальный микрофон → AudioWorklet → pitchy → запись → результат. Сигнал синтезирован на −5 полутонов с намеренной ошибкой в 5–6,2 секунды; UI показал сдвиг −5, примерно 97 баллов и нужный фрагмент.
- Отсчёт, piano roll, таймлайн, обе версии A/B, переключение во время воспроизведения, оба движка, переслушивание ошибочного фрагмента.
- Копирование вызова; ссылка одной проверенной production-попытки — **452 символа** (длина немного меняется с задержкой виртуального устройства).
- Вторая вкладка: приём вызова, призрачная линия, новое исполнение, экран дуэли и сравнение осей. Разрешение 1440 и затем 390 px.
- Отказ в доступе к микрофону и повреждённый вызов показывают русское сообщение, приложение остаётся доступным.
- Необработанных ошибок JavaScript в основном прогоне нет. Дополнительная проверка главной и прослушивания на 320 px не обнаружила ошибок консоли; сетевые обращения были только GET к своему origin.

Просмотрены снимки главной на desktop/mobile, результата, дуэли и графика призрака. Выборка сохранена в [docs/qa/](docs/qa/).

**Граница проверки:** синтетический источник вместо человека, Chromium вместо физических iOS/Android. Запуск A/B подтверждён программно; субъективное качество тембра и музыкальной коррекции человеком не оценивалось.

## Python и музыкальные файлы

- `make_demo_songs.py` успешно создал два комплекта MP3/WAV/JSON.
- Установлены зависимости `tools/requirements.txt` в изолированное Python-окружение.
- `make_reference.py` (librosa pYIN) обработал 20-секундный синтезированный вокал: **2000 кадров, hop 10 мс, 2 фразы**.
- Медианная ошибка извлечённой высоты на совместных голосовых кадрах относительно исходного численного эталона — **0,79 цента**.
- Ни одна сторонняя фонограмма для демо не использовалась; уведомления production-зависимостей сохранены в `THIRD_PARTY_NOTICES.txt` и включены в `public/`.
