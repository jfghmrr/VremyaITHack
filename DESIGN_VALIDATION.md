# Проверка новой визуальной версии ЭХО

Дата: 12 октября 2026. Изолированный Google Chrome 154.0.8037.98, без личного профиля. Проверены локальный Vite и статическая production-сборка на 127.0.0.1:5174. Публикация не выполнялась.

## Что проверено

- После каждого из пяти экранов: `npm test` — 22/22, TypeScript и Vite build успешны, локальная страница отвечает. Каждый экран — отдельный коммит.
- Исходные `src/audio`, `src/scoring`, `src/challenge`, эталоны и тесты не менялись.
- `npm run score:demo`: идеал, +5, −7, задержка 200 мс, вибрато — 100; фальшивое пение — 23,9; тишина — 0; смена тональности — 87,3 при интервалах 100 и стабильности 15; одна нота — 30.
- Полный браузерный путь с синтетическим входным звуком через настоящий AudioWorklet/pitch detector: имя → песня → разрешение → выбор USB-входа → пение → результат → обе звуковые версии → переслушивание → clipboard → ссылка во второй вкладке → призрак → дуэль.
- Пробел останавливает и продолжает время; Esc ставит запись на паузу и открывает подтверждение; Esc в диалоге отменяет, Enter подтверждает; R повторяет попытку; ввод имени не перехватывается горячими клавишами.
- Проверены отказ в доступе, отсутствующее и занятое устройство, нулевой уровень, запрет clipboard с ручным копированием.
- 30 проверок размеров и состояний; основные экраны при 1366×768 и 1920×1080 не требуют вертикальной прокрутки. В 800 px доступен адаптив со скроллом. Отдельно проверен результат в 390 px.
- Для дуэли дополнительно проверено расстояние между колонками игроков и проигрывателем: не меньше 8 px.
- A/B: изображение отличается в процессе перехода и после него, возвращается к исходному; в reduced-motion нет продолжающейся интерполяции. Проверены Tab и видимая рамка фокуса.
- HiDPI: ширина Canvas при DPR=2 соответствует удвоенной CSS-ширине. Обновления объединяются через requestAnimationFrame; вывод не меняет аудиопоток.

Точный журнал финального запуска: [checks.json](docs/qa/identity/checks.json), [interaction-checks.json](docs/qa/identity/interaction-checks.json). Локальный замер частоты кадров относится только к этой машине, синтетическому входу и указанным размерам. Это не измерение задержки микрофона или качества звука.

## Повторить проверку

Из корня проекта, при работающем dev-сервере:

```sh
npm test
npm run build
npm run format:check
npm run score:demo
node docs/qa/identity/check.mjs
node docs/qa/identity/interactions.mjs
```

Для статической сборки сначала запустить `npx vite preview --host 127.0.0.1 --port 5174`, затем перед браузерной командой указать `ECHO_BASE_URL=http://127.0.0.1:5174/`.

Оригинальные браузерные скрипты в tools сохранены без изменений по условию задачи. Их текстовые селекторы относятся к предыдущему UI. Актуальные копии с новыми подписями и дополнительными визуальными проверками находятся рядом со скриншотами; тесты скоринга не редактировались.

## Ограничения и демо

- Физические микрофоны, проектор и воспроизведение человеческого голоса на слух не проверены. На сцене нужны наушники и предварительная проверка выбранного входа.
- Edge, Firefox и Safari в этом проходе не проверены. Для выступления используйте Chrome.
- «Идеальный я» по умолчанию остаётся синтезированным ориентиром; обработка собственного голоса экспериментальная и может искажать тембр. Переключение графика показывает желаемую высоту, не обещает идеальной звуковой коррекции.
- Сдвиг −5 появляется из исполнения, не подставляется интерфейсом. Хорошее исполнение может дать меньше трёх заметных ошибок.
- В несжатом разборе и дуэли возможны небольшие различия балла из-за передачи кривой с шагом 50 мс; алгоритм общий и не менялся.
- При масштабе браузера больше 100% или окне ниже 768 px возможна прокрутка. Она не запрещена искусственно, чтобы управление оставалось доступным.
- Если будет ещё время: прослушивание коррекции с разными голосами, проверка нескольких физических входов в Edge, проверка контраста на проекторе и полноценный аудит с экранным диктором.
