# Проверка версии Perepev 3

20 октября 2026 года. Исходники взяты из переданной командой папки `Perepev 3`. Проверка выполнена на macOS ARM64 в отдельном Docker-проекте `perepev-v3-qa`, порт 8089, с новыми томами. Рабочий сайт и его база для тестов не использовались.

## Сборка и автоматические проверки

| Проверка | Результат |
| --- | --- |
| Docker: Rust API, WASM, статический сайт | Сборка успешна; четыре сервиса запущены и прошли healthcheck |
| Локальный и серверный Compose | Конфигурации корректны; для серверной подставлены тестовые домен и пароль |
| Rust workspace | 74 теста пройдены |
| Clippy | Без предупреждений с `-D warnings` |
| Svelte / TypeScript | 0 ошибок, 0 предупреждений |
| Vitest | 338 тестов в 34 файлах пройдены |
| JSON-схемы и типы API | Повторная генерация не изменила файлы |
| Интеграционные сценарии API | 65 пройдены с настоящими PostgreSQL и Valkey |
| Python без запуска моделей | 127 тестов пройдены, 4 модельных исключены |
| Презентация | 10 слайдов; PPTX читается как корректный архив, копия совпадает с исходным файлом |

Полный `cargo fmt --check` выдаёт различия со стандартным форматированием rustfmt и в этой версии, и в предыдущем коммите `89ef028`. Массовая переформатировка Rust-файлов в это обновление не включена; проверка Clippy пройдена отдельно.

Интеграционный прогон использовал отдельную базу PostgreSQL `perepev_v3_test` и базу Valkey 12. Проверены несколько экземпляров API, очередь, восстановление матчей, совместные голоса, права доступа, отзыв согласия, правка текста своего трека и повторное применение миграции 7. OAuth и GPU проверялись через тестовых провайдеров и ответы обработчика.

## Браузер

Успешно пройден **61 различный сценарий** с учётом браузерного движка. Повторы после первого запуска в итоговое число не включены.

| Набор | Движок | Пройдено |
| --- | --- | --- |
| Кабинет и вызов-призрак | Chromium | 2 |
| Настоящие голоса, повторное открытие результата, отказ загрузки и отзыв согласия | Chromium | 5 |
| Совместная игра и реванш | Chromium | 3 |
| Одиночное пение, разбор и тренировка | Chromium | 1 |
| Мобильное меню и закреплённые панели | Chromium | 14 |
| Правка слов и таймингов своего трека | Chromium | 2 |
| Страница 404 и сбой загрузки | Chromium и WebKit | 8 |
| Телефоны, настольные экраны, пение и поворот телефона | Chromium и WebKit | 26 |

Использованы `account.spec.ts`, `coop-voices.spec.ts`, `coop.spec.ts`, `solo.spec.ts`, `tabbar.spec.ts`, `tracks-lyrics.spec.ts`, `error-page.spec.ts`. Из `responsive.spec.ts` выполнены группы `phone`, `desktop` и поворот телефона. Это выбранный набор, а не все браузерные тесты проекта.

Размеры матрицы: 360×740, 390×844, 430×932, 844×390, 932×430, 1280×720, 1366×768, 1920×1080, 2560×1440 и 3440×1440. Планшетная группа матрицы не запускалась; нижнее меню отдельно проверено на 768×1024 и 1024×768. Просмотрены снимки главной, сцены пения и результата на телефоне и компьютере.

Проверки используют отдельные браузеры и синтетический микрофон. Настольные и мобильные размеры проверяются как браузерная эмуляция. Это не тест физических Android/iPhone.

В первом общем запуске тесты израсходовали лимит 12 регистраций с одного адреса за 15 минут и получили 429. Дальнейшие сценарии разделены на группы; перед каждой очищался только счётчик регистраций отдельного тестового стенда. Ограничения приложения не менялись.

В новой папке оказался прежний адрес теста ошибки `/songs/missing/deeper`. На Docker-сайте `/songs/*` занят статическими файлами, поэтому восстановлен путь страницы приложения `/missing/deeper` и ожидание загрузки клиента.

## Как повторить

Rust и клиент:

```sh
cargo test --release --workspace
cargo clippy --release --workspace --all-targets -- -D warnings
cd web
npm ci
npm run check
npm test
npm run build
```

Интеграционные тесты требуют собранный `target/release/perepev-api`, `psql`, `valkey-cli` и **отдельные тестовые базы**. Набор очищает указанные хранилища:

```sh
TEST_DATABASE_URL=postgres://USER@localhost/perepev_test \
TEST_VALKEY_URL=redis://127.0.0.1:6379/1 \
node --test --test-concurrency=1 tests/integration/
```

При использовании удалённого Valkey настройте также адрес для `valkey-cli`: вспомогательный скрипт вызывает его отдельно от API.

Браузерные проверки запускаются из `web`:

```sh
npx playwright install chromium webkit
BASE_URL=http://127.0.0.1:8089 npx playwright test error-page.spec.ts
BASE_URL=http://127.0.0.1:8089 npx playwright test coop.spec.ts --project=chromium
```

Полный набор создаёт много пользователей и может упереться в лимит регистраций. Запускайте его группами на отдельном стенде, учитывая окно лимита. Не очищайте лимиты действующего сервера ради тестов.

Python, из `gpu-worker`:

```sh
uv sync --frozen --extra cpu
uv run --frozen --extra cpu pytest -m "not models"
```

## Границы проверки

Настоящая обработка на Windows/GPU, физические микрофоны, Bluetooth и вход через реальные Яндекс ID/VK ID в этом прогоне не проверялись. Там, где сценарии требуют ответа обработчика, используются тестовые ответы. Число тестов не является измерением качества оценки живого пения.

Публичный адрес `perepev.lumnex.ru` указан командой как адрес развёрнутого сайта. Из среды проверки подтвердить его доступность не удалось: запрос завершился по тайм-ауту. Это само по себе не подтверждает сбой сайта.

Предыдущие результаты сохранены отдельно: [проверка 17 октября](release-2026-10-17.md) и [GPU-бенчмарк 16 октября](../gpu-worker/bench/RESULTS.md). Их результаты не прибавляются к текущему прогону.
