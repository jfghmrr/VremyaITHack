# Обновление к защите: принятые решения

16–17 октября 2026 года. Это запись проектных решений. Актуальное устройство приложения описано в [архитектуре](../../../ARCHITECTURE.md), результаты проверок — в [отчёте](../../release-check.md).

## Задача

Подготовить браузерное караоке к показу: удобное пение на узком экране, понятный результат, знакомые песни, загрузка своего фрагмента и обработка записи отдельным GPU-компьютером. При отказе обработчика пользователь должен получить локальную оценку.

## Что вошло

- Раскладки по ширине, высоте и ориентации; безопасные области экрана, крупные кнопки и удержание экрана включённым во время пения.
- Точная оценка одиночной попытки с проверкой слов и сходства с дорожкой подсказки, по отдельному согласию пользователя.
- Личные треки: выбор 15–60 секунд, до пяти загрузок в сутки, хранение 24 часа.
- Восемь дополнительных песен. Итоговый каталог — 32 записи, 14 на русском и 18 на английском.
- Вход через Яндекс ID и VK ID, формы согласия и обращения, возрастная группа в регистрации.
- Установка обработчика на Windows и работа через исходящие HTTPS-запросы.
- Развёртывание за существующим nginx, без занятия портов других сайтов контейнерами.

## Изменения относительно первого замысла

Первоначальная цель в 50 песен сокращена до 32: готовность записи, атрибуция и качество эталона оказались важнее количества. Необработанные кандидаты перечислены [отдельно](../../catalog-candidates.md).

Для распознавания выбран `openai-whisper`, а не `faster-whisper`, чтобы не добавлять зависимость от CTranslate2 при установке на Windows. Модели не обучались с нуля. Apple MPS отключён после проблемы с памятью; CPU оставлен для разработки.

Очередь GPU-заданий размещена в PostgreSQL. Valkey продолжает обслуживать подбор соперника и временное состояние дуэлей. Исходный вариант публикации через Caddy на 80/443 заменён для действующего сервера на nginx → Caddy; отдельная конфигурация Caddy сохранена для других установок.

## Границы версии

Дуэли продолжают использовать серверную оценку кривой высоты без распознавания слов. Свои треки доступны только владельцу. Регистрация и страницы документов не доказывают соблюдение всех требований к публичному сервису; фактические реквизиты, права на материалы и серверные настройки проверяет владелец.

Бенчмарк на преобразованных студийных записях проверяет отдельные свойства алгоритма. Он не заменяет испытания с людьми, разными микрофонами, шумом и Bluetooth. Эти проверки остаются следующим этапом.
